Methodology
UMSI = 0.20T + 0.20C + 0.20B + 0.15V + 0.10P + 0.10D + 0.05A
Scores use rolling historical percentiles. Fear-oriented raw variables (VIX, VIX/VIX3M, HY OAS, put/call) are inverted so 100 is risk-on. Market breadth uses an RSP-versus-SPY relative-performance proxy in this free-data version. When a historical AAII or put/call observation is unavailable, the available weights are re-normalized and calculation_quality records how much of the target model was present before re-normalization.

Stress = term structure + credit + VIX + drawdown pressure. Fragility = low-volatility complacency + curve complacency + narrow breadth + AAII optimism + low put/call + concentration proxy + price stretch. Fragility is a vulnerability measure, not a forecast.
